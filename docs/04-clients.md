# 4. Подключение LLM-клиентов

Сервер общается с клиентами по протоколу MCP через HTTP. Настройка везде
сводится к трём вещам:

- адрес: `http://<хост>:3100/mcp` (именно с `/mcp` на конце);
- заголовок: `Authorization: Bearer <MCP_AUTH_TOKEN>`;
- режим "Агент" в клиенте — в обычном чате инструменты не вызываются.

`<хост>` — адрес машины, где запущен Docker. Если клиент работает на ней же,
подойдёт `127.0.0.1`.

Обычно подключение MCP задается через файлы конфиги. Например, в VS Code
в корне проекта файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "ws-hcm-ai-assistant": {
      "type": "http",
      "url": "http://<хост>:3100/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_AUTH_TOKEN>"
      }
    }
  }
}
```

Сервер поддерживает и устаревший транспорт SSE (`http://<хост>:3101/sse`).

После подключения рекомендуется положить в проект правила из
[05-prompts.md](05-prompts.md): с ними модель работает более корректно.

Для проверки спросите модель любой вопрос, например, «Какие поля есть у объекта
collaborator?». Она должна корректно ответить, а не по памяти и не придумать.
