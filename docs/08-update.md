# 8. Обновление, откат, удаление

## Обновиться до свежей сборки

```bash
docker compose pull
docker compose up -d
```

Первая команда скачивает образ по тегу из `.env` (`ASSISTANT_TAG`, по умолчанию
`latest` — всегда последний выпуск), вторая пересоздаёт контейнер.

Проверка:

```bash
curl http://localhost:3100/healthz
```

Поля `version` и `built_at` должны измениться.

Перед обновлением загляните в [CHANGELOG.md](../CHANGELOG.md): там написано,
что изменилось и нужно ли что-то сделать руками (например, добавить
переменную в `.env`).

**LLM клиенты держат список инструментов с момента подключения.** После
обновления перезапустите MCP клиент в IDE — иначе модель не увидит 
новые инструменты, а про старые будет думать, что они есть.

## Обновить только ключ лицензии

Замените строку `LICENSE_KEY=` в `.env` и выполните `docker compose up -d`.
Образ при этом не меняется. Актуальный ключ и дата его окончания — в
[.env.example](../.env.example), условия — в [LICENSE-BETA.md](../LICENSE-BETA.md).

## Остаться на конкретной версии

В `.env`:

```ini
ASSISTANT_TAG=2.3.0-beta.1525
```

и `docker compose up -d`. Тогда `docker compose pull` не подтянет новую сборку.

Список версий — в разделе [Releases](../../../releases) и в
[CHANGELOG.md](../CHANGELOG.md).

## Что переживает обновление

| Что | Где лежит | Переживает |
| --- | --- | --- |
| Настройки | `.env` | да |
| Логи и телеметрия | `./logs` | да |
| Модель поиска и векторы | `./models` | да |
| Индекс дашборда | том `mcp-index` | да |
| Сам сервер | образ | заменяется |

## Три способа потерять данные AI ассистента

1. **`docker compose down -v`** — удаляет тома, вместе с ними индекс
   дашборда. Логи в `./logs` остаются, индекс можно потерять безвозвратно.
   Для остановки достаточно `docker compose down` (без `-v`) или
   `docker compose stop`.
2. **Перезапись `docker-compose.yml` поверх своих правок** при обновлении. 
   Свои настройки держите в `.env`, а нестандартное — в
   `docker-compose.override.yml`: этот файл Compose подхватывает
   автоматически и обновление его не трогает.
3. **Удаление `.env`** — вместе с ним уйдут пароли и токен. Держите копию в
   надёжном месте (но не в публичном репозитории).

Новые переменные в новых версиях всегда со значением по умолчанию: сервер
запустится и со старым `.env`. Список новых переменных — в разделе
CHANGELOG для соответствующей версии.

## Остановить

```bash
docker compose stop      # остановить, всё сохранить
docker compose down      # удалить контейнер, тома оставить
```

## Удалить полностью

```bash
docker compose down -v
docker image rm ghcr.io/spololin/ws_hcm_ai_assistant:latest
```

Останутся только `./logs`, `./models` и `.env` — удалите их вручную, если
они больше не нужны.
